# Step Quiz

Webs de matemàtiques i de programació, en català, per a l'alumnat i el professorat de secundària.
Les fa **David Arso Civil** per al Departament de Matemàtiques de l'INS Miquel Tarradell (Barcelona).

Totes són pàgines estàtiques (HTML, CSS i JavaScript, sense servidor ni instal·lació) i es publiquen
amb Cloudflare Pages des de la branca `main` de cada repositori.

**Comença per aquí:** [step-quiz.net](https://step-quiz.net) (activitats) ·
[ins.step-quiz.net](https://ins.step-quiz.net) (portal de recursos de l'institut)
